# 铁路大亨 · 下一站推测

读游戏右侧面板的剩余站点，算出下一站最可能是哪种店。

小窗口贴在屏幕右下角，游戏在后台或被挡住都能读。不点击游戏、不模拟按键、不联网。

**[下载最新版](https://github.com/ts471002/railway-tycoon-bot/releases/latest)**（Windows 10 1809 以上，92MB）

## 怎么用

1. 双击安装包，选个安装位置，装完桌面有图标
2. 打开游戏，停在有右侧面板的界面（大地图、进站选择都行）
3. 双击图标。走到下一站，数字变了就会自动更新

第一次启动要 3~7 秒，在找面板位置，之后每次 0.5~0.7 秒。

卸载：删掉安装文件夹和桌面图标。

## 怎么算的

面板上的两个数字是已知条件：每种店还剩几个、未来几站哪种最多。

再排除两种不可能的情况：

- 不会连续三站相同
- 每种店一局最多 6 个

把满足条件的排列全列出来，数一数每种店占多少，就是概率。游戏如果有别的规则，它不知道。

## 读不到怎么办

先确认两件事：游戏窗口没最小化（最小化后抓不到画面），当前界面上确实有那块面板（商店、设置界面没有）。

还是读不到，点界面上的「**校准**」：会弹出当前画面，按住左键框住右侧那一整块（「未来3站…」和「旅程剩余站点：…」都要在里面），松手会显示认到的字，认对了点「就用这个位置」。框一次以后一直用。

想让它忘了重找：双击右上角那个「● 在线」小圆点。

**画面尺寸不对**：程序说 1280×720，你的屏幕是 1920×1080，是 Windows 显示缩放（150%）造成的。把「设置 → 系统 → 显示 → 缩放」改成 100%，或者把游戏设成窗口化。

## 其他

- **重置**：这一局结束了，清空记录。下一局开始时会自动重新记。
- **杀毒报毒**：误报。程序会解压自己再运行，行为像病毒，加个信任就行。
- **为什么 92MB**：识别模型和图像库占大头。因为全在本地跑，所以不用联网。

<summary>构建、调试、文件说明</summary>

需要 Python 3.11+，Windows 10 1809 以上。

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
铁路大亨推测.bat          :: 源码启动
打包安装版.bat            :: 生成 dist\铁路大亨推测-安装版.exe
```

调试：

```bat
.venv\Scripts\python.exe tools\next_station.py        :: 读一次，打印结论
.venv\Scripts\python.exe tools\next_station.py dump   :: 打印所有 OCR 文字
.venv\Scripts\python.exe tools\panel_regression.py    :: 回归测试，6 种分辨率都要读到
铁路大亨推测.exe --selftest                            :: 自检，写 logs\selftest.txt
```

改了读屏逻辑就跑一遍 `panel_regression.py`。小窗口字被压小、面板贴在左边这两个问题，本机复现不出来。

| 文件 | 作用 |
|---|---|
| `installer.py` | 安装器：选路径、解压、建快捷方式 |
| `launcher.py` | 入口，带 `--selftest` |
| `tools/next_station.py` | 读屏、OCR、解析、纠错 |
| `tools/next_station_gui.py` | 界面 |
| `tools/panel_calib.py` | 校准窗口 |
| `bot/bgcapture.py` | WGC 后台抓屏 |
| `bot/ocr.py` | RapidOCR |
| `bot/journey.py` | 概率求解 |
| `bot/dpi.py` | DPI 感知 |

面板定位是四级降级：记下的位置 → 标准位置 → 三条竖带 → 全屏分块。找不到就往下走一级，找到就记住。后两级只在连续失败后才跑，有退避，不会一直占 CPU。

`.venv/`、`build*/`、`dist/`、`data/`、`logs/` 都在 `.gitignore` 里。
